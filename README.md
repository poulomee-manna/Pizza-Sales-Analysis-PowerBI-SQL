# 🍕 Pizza Sales Analysis Dashboard | SQL + Power BI

## 📌 Project Overview

This project presents an end-to-end Pizza Sales Analysis Dashboard developed using SQL and Power BI. The objective is to analyze pizza sales performance, identify customer ordering trends, evaluate product performance, and generate business insights through interactive dashboards and KPI reporting.

The project demonstrates the complete data analysis workflow, including SQL-based data analysis, data transformation, KPI calculation, and dashboard development to support data-driven decision-making.

---

## 🎯 Business Objective

The main objectives of this project are:

- Analyze overall sales performance.
- Track key business KPIs.
- Identify daily and monthly sales trends.
- Analyze pizza category and size performance.
- Identify top and bottom-performing pizzas.
- Provide actionable business insights through interactive dashboards.

# 💡 Business Insights

- Weekend evenings recorded the highest number of orders.
- March generated the highest monthly order volume.
- The Classic pizza category contributed the highest share of sales.
- Large-sized pizzas generated the maximum revenue.
- Thai Chicken Pizza was the highest revenue-generating pizza.
- Brie Carre Pizza generated the lowest revenue.
